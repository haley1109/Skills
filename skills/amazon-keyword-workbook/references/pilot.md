# 服装试跑记录

本例验证了美国站一款粉色缎面短吊带睡裙的建库流程。在售变体包含单裙和睡裙配睡袍。下面的数值仅供复核本案。每个新项目都需向用户确认相似商品的定义和分档阈值。

## 从数据源到完整操作表

| 项目 | 试跑结果 |
| --- | --- |
| ABA 原始数据 | 正向 504 条、反向 7 条。两张原表合计 506 个完全不同的原词 |
| 西柚父体反查 | 两个竞品父体分别返回 1,823 和 2,444 个词。跨父体按原文去重后共 3,535 个 |
| 三路汇总 | 共 3,877 个原词。同一排名下的不同词均保留 |
| 交付结构 | 一份完整操作表，保留三张来源表，并含「竞品反查」「待筛查词库」「词库」「否词表」 |

本案按用户要求保留了手工编辑的旧「待筛查词库」，其中只有首个词有示范链接，原顺序也得以保留。「词库」中的 3,877 行均有可点击链接和搜索网址，且按 ABA 排名排序。以后新生成「待筛查词库」时即需逐行写入两列、核对数值排序和缺排名排末，再从它生成「词库」。

## 相关性证据覆盖

此项目采用同一相似商品口径。相似占比达到 50% 为强相关，达到 20% 且低于 50% 为相关，低于 20% 为不相关。分母为范围内去重后的商品数，包含信息不足的商品。若把信息不足的商品全部计为相似会改变档位，则按已确认占比暂定档，并标明「下限」。

| 相关性依据 | 原词数 | 如何理解 |
| --- | ---: | --- |
| 亚马逊首页 | 1,530 | 对实际首页主结果区商品卡计数。区内广告计入，同一 ASIN 只计一次 |
| 西柚历史自然首页 | 219 | 同一采集时点、同一词的完整首页自然位记录。本案为 1 至 48 位 |
| 西柚自然位样本 | 13 | 同次采集的部分首页自然商品，分母为实际观察的样本量 |
| 亚马逊首页（用户实查） | 1 | 用户复核后确定档位，未提供逐件计数 |
| 词义初判 | 1,905 | 按购买意图及在售变体初判 |
| ABA 商品辅助初判 | 209 | 结合 ABA 点击商品佐证意图 |

以上 3,877 词中，1,762 词按商品计数复算，其中 358 词带「下限」。2,114 词沿用初判，另有 1 词用户实查。最终 23 词强相关、483 词相关、3,371 词不相关。举例来说，`satin nightgown` 的首页去重后有 60 件商品，确认相似 38 件，占 63.3%，按本案标准判强相关。`pink satin nightgown` 的强相关档位来自用户实查，保留了该依据。

## 否词归因

用全部 506 个强相关及相关原词检查误伤。3,371 个不相关原词均可在「否词表」追溯。2,272 个可归因，其中 1,123 个仅能在原词组合中使用。其余 1,099 个保留原词复核，其中 1,040 个缺少可独立归因的属性，59 个词义待核对。

汇总得到 516 个词根或短语，其中 348 个可提取为词根，168 个限原词组合。比如 `blue nightgown` 的归因是颜色 `blue`，它覆盖 69 个本案不相关词，在本案相关及强相关词中命中 0 个。`black` 虽覆盖多个不相关词，也命中 5 个相关或强相关原词，因此列为「限原词组合」。睡袍属于实际在售套装，一页大多是单件睡袍时，可以判整词不相关，同时保留 `robe` 在套装词中的有效性。
