# 逐词判定与复核

## 确定本项目的范围

每次新建词库，确认两个门槛是否含等号、强相关和相关各统计什么商品。记录本次任务使用的站点、子体或父体变体范围、取首页哪个区域及广告口径。若按以往操作，使用美国站首页主结果区，包含其中的广告卡，独立推荐轮播不计。同一 ASIN 在该页只算一次。向用户说明实际采用的口径。

把可核实的款式与用途作为比较基准。商品卡优先看图片、标题及可核实的在售变体。相似表示买家可以把目标商品当作该组商品的合理替代。搜索词写出的颜色、规格、材质有助于理解意图，但以实际展示的商品与在售款比较。例如搜 16×16 英寸枕套时，如果页面有大量 18×18 英寸商品，18×18 英寸的目标款仍可能相关。搜索详情不清楚的商品保留为不确定。

## 收集证据

| 相关性依据 | 取证和记录 |
| --- | --- |
| 亚马逊首页 | 保存关键词原文、URL、查阅日期、结果区及去重 ASIN。逐件保留非常相似、相似、不相似或不确定的决定及可核对的标题或图像依据。只有真实读取过的页面才填此项。 |
| 亚马逊首页（用户实查） | 采用用户对该词该页面明确给出的复核档位并留日期。未给商品计数时，比例留空。 |
| 西柚历史自然首页 | 首页无法取到时，以 `get_keyword_asin_analysis` 中同原词、同站点、同一采集时点、第一页的自然商品为依据。核对名次范围和连续性，按实际容量判断是否完整，保留观察时间和覆盖名次。 |
| 西柚自然位样本 | 同一时点只覆盖部分首页时，以去重后的实际样本数为分母并标样本。核对其覆盖范围和代表性。不可将多日名次或不同页面的商品拼成一次全页。 |
| ABA商品辅助初判 / 词义初判 | 商品证据不足时，结合词义、商品及在售变体给初判。当 ABA 热门点击商品确实提供了额外线索，标注辅助初判。点击份额和竞品排名均不能替代相似商品比例。 |

遇到亚马逊验证、无结果或页面残缺，记录状态并转用可取得的证据。词义和实际结果指向不同时，优先本次真实页面。用户提供新的现场复核时保留其结论和来源。新的数据能改动旧结论时可以更新，并保留复核记录。

## 计算与报告

逐词保留去重后商品总数 N、非常相似数 V、普通相似数 S、不相似数 D、不确定数 U，四项互斥且合计等于 N。若本项目两档都用相似商品，分子是 V+S。若强档只计非常相似，则强档分子是 V。先检验强档，再检验相关档。按未舍入的分数比较，显示时再四舍五入。N=0 时转入其他证据来源。

若本项目将不确定商品计入分母，已知分子除以 N 是下限，把 U 加入分子可得上限。区间跨越档位时优先复核不确定商品。仍无法核实时，按约定给出暂定等级，并在依据中标「下限」。留存当次门槛、分子定义、逐词计数及时间。只改门槛时，用同一批观察重新计算可计数的词，并单独列明初判和人工复核的处理。只有结论的记录没有实测比例。

在「词库」逐词写来源并附必要的分子、分母或可追溯位置。交付时将来源计数加总到全库词数，同时说明超出或跨越门槛的不确定项。「下限」是计数词的子集。复查否词时以全部正向词做交叉核查，低证据的「不相关」结论不能单独证明其任一词根有排除价值。
